## Utah Teapot

Official source and terms: https://graphics.cs.utah.edu/teapot/
Historic Utah Teapot developed at the University of Utah by Martin Newell. This mesh uses the 1987 Frank Crow exterior with round bottom, generated by the official page's current generator. The official model files are freely available for any use including commercial use, with a request to identify the Utah Teapot and acknowledge its University of Utah origin.

Export: triangle resolution 24, both sides, Blinn scale, round bottom, no interior, patch UV coordinates, symmetric triangulation; shared positions are split when normals/UVs differ. Positions/normals are changed from Z-up to Y-up, face winding adjusted accordingly, and the arrays stored in the homework's JSON mesh schema. Model geometry and UVs otherwise retain the official output. 19,992 vertices / 36,672 triangles. Generator option bitmask and file hashes are in `scenes/npr/teapot_source.json`.

The source shader repository references `Models/teapot3.obj` but does not include it. Our mesh is a documented replacement, not claimed to be the missing original. A low-resolution test mesh from another repository was discarded and is not part of this delivery.
